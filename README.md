🏦 ATM Management System (Python)
📌 Project Description

This project is a menu-driven ATM application developed using Python.
It simulates basic ATM operations such as Deposit, Withdraw, and Balance Enquiry with proper exception handling and modular programming.

The project is designed to demonstrate core Python concepts including functions, custom exceptions, control flow, and modules.

🛠️ Technologies Used

Python

Exception Handling

Modular Programming

Match-Case (Python 3.10+)

📁 Project Structure
ATM_Project/
│
├── menu.py
├── exceptions.py
├── ATM_Operations.py
└── main.py

📋 Features

Menu-driven user interface

Deposit money with validation

Withdraw money with balance check

Balance enquiry

Custom exception handling for:

Invalid amount

Negative or zero values

Insufficient funds

Clean and modular code structure

⚙️ How the Project Works

User selects an option from the ATM menu

Program validates user input

Performs deposit / withdrawal / balance enquiry

Displays updated balance

Handles invalid inputs using custom exceptions

▶️ How to Run the Project

Install Python 3.10 or above

Download or clone this repository

Open the project folder in PyCharm / VS Code

Run the main.py file

python main.py
